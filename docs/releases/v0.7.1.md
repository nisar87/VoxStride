# VoxStride 0.7.1

Fixes speech for quiet microphones, and switching to cloud speech now works without a restart.

## Fixed
- **Quiet microphones are no longer ignored.** Some headsets send clean but very quiet audio. Cloud speech threw every sentence away as "too short", so nothing was detected, and the offline engine guessed badly ("too soft"). VoxStride now boosts quiet speech inside the app, up to 16×, without clipping. It does not change any Windows or microphone setting. Loud microphones are unaffected.
- **Saving a Gemini or OpenAI key switches to cloud speech straight away.** Changing the speech engine or mic sensitivity also applies without a restart. If you're speaking an instruction, the new engine starts with the next one, so nothing is cut off.

## Diagnostics
- The log now shows the boost (`gain=`), the room noise and speech level per session, and every utterance sent to cloud speech or skipped as too short. Speech problems can be traced straight from the log.
