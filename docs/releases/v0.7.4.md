# VoxStride 0.7.4

Fixes voice input with Gemini, which 0.7.3 broke.

## Fixed
- **Speech stopped working with Gemini in 0.7.3.** To make transcription faster, 0.7.3 asked Gemini for its lowest ("minimal") thinking level. The Gemini model you use refuses that level, so every sentence failed with "Thinking level MINIMAL is not supported". VoxStride now never depends on a single setting. If Google rejects a thinking level, it immediately retries with the next one ("low", then the model's own default) and remembers what that model accepts. The same protection applies to Gemini requests, not just transcription.
