# VoxStride 0.7.0

The final audit against the master plan, with measured evidence and release hygiene.

## New
- **Licence and notices.** VoxStride is proprietary (all rights reserved; personal use of the released installer is allowed). Third-party components and their licences are listed in `THIRD-PARTY-NOTICES.md`, which is installed next to the app.
- **SBOM.** Every release now carries an SPDX 2.3 software bill of materials (`VoxStride-<version>.spdx.json`) listing every package and version.
- **Measured performance** on the installed build (GitHub Windows runner):
  - Direct commands: p50 5.7 ms and p95 8.5 ms over 30 runs.
  - Idle: CPU 0.18 % and 148 MB of memory over 60 s.
  These checks run on every build.

## Documentation
- Architecture, user manual, threat model (UI control, browser extension, IPC, screenshots, updates), acceptance tests, traceability and roadmap are updated for everything built since 0.3.
- New design records:
  - ADR-0010: UI Automation worker and screenshot fallback.
  - ADR-0011: browser extension bridge.
  - ADR-0012: natural turns are read-only.
