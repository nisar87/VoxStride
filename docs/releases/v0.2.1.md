## VoxStride 0.2.1

- Readable popup: dark card with white text in both light and dark Windows themes.
- Better listening: Windows online dictation (free, no key) when Windows "Online speech recognition" is on. Optional OpenAI/Gemini cloud speech for accents and mixed Urdu/English.
- Microphone: choose your microphone, live **Test microphone**, and a fix for the default-microphone bug on 64-bit Windows. If your mic is silent, VoxStride tells you which microphone does hear you.
- Teams/Zoom friendly: VoxStride stops background listening while another app is using the microphone.
- No more false "no microphone signal" warnings.
- Diagnostics log (no spoken words, keys or audio) under About › Open log folder.
- Updates install from the **Install update** button, or automatically when you're not using VoxStride.
