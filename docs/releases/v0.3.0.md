## VoxStride 0.3.0: voice input rebuilt

VoxStride wasn't hearing anything you said. Two faults caused it, and both are fixed at the root:

- **The offline speech engine was fed audio the wrong way.** Windows stopped listening after the first fraction of a second, so it never received your words. Audio now flows to the engine correctly and continuously.
- **The microphone could stay open after listening.** In some cases VoxStride didn't release the microphone when listening ended. Now one part of the app owns the microphone. It opens the mic only while VoxStride is actually listening and always releases it afterwards.
- **Windows online dictation is removed.** Windows only allows it for Store-packaged apps, so it could never work in this version and always failed. VoxStride now uses cloud speech if you've added an OpenAI or Gemini key and turned it on, and otherwise the offline Windows engine.
- **New: Voice › Test speech.** It listens for 6 seconds with the real speech engine and shows the words it understood, so you can see whether VoxStride hears you, not just whether the microphone makes a sound.
- **Changing the microphone applies straight away** when you click Save. No restart needed.
- **Fewer false alarms.** A quiet pause no longer interrupts your instruction with "I can't hear anything". You get a gentle hint instead, and a real fault (the microphone sends no audio at all) is reported clearly.
- **Better logs.** The diagnostics log now records which microphone was used, how much audio arrived, and how many words were recognized in each session.
- **Smaller downloads.** A Windows component that was only needed for the removed dictation engine is no longer included.

Your Windows settings are not touched.
