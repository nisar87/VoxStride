## VoxStride 0.5.0: control other apps

VoxStride can now work inside the apps on your PC, not just open them.

- **See open windows and switch between them** ("switch to Excel").
- **Read an app's buttons, boxes, menus and lists, and use them**: press buttons, tick boxes, choose items, open menus, fill in text boxes and type text. It uses Windows' accessibility system, so it works with most apps.
- **Safety first:**
  - Buttons like Send, Delete, Pay, Submit or Buy always ask for your approval first.
  - VoxStride never types into password fields.
  - It never touches Windows security prompts, sign-in screens, or apps you've blocked.
  - Typing stops instantly if you switch windows or move the mouse.
- **When an app can't be read**, VoxStride can ask to take a screenshot of that one window so the AI can see it. It asks every time (or never, if you switch screenshots off). Clicks based on a screenshot also need your approval, and only happen if the window hasn't moved and nothing is covering that spot.
- **A frozen app can't freeze VoxStride.** Slow apps time out and VoxStride carries on.

Tested on Windows with a test app: filling text, pressing buttons and ticking boxes each succeeded 100 out of 100 times.
