## What's new in VoxStride 0.2.0

**Understands you better**
- New optional cloud speech recognition (OpenAI `gpt-transcribe` or Gemini) for accented English and mixed Urdu/English. Turn it on under **Voice → Use cloud speech recognition**. Your voice is sent only while you're giving an instruction, never in standby.
- The finish phrase now tolerates accents ("box stride execute", "VoxStride exicute"), and you can also say **"VoxStride, chalo"** or **"VoxStride, karo"**.
- Adjustable microphone sensitivity.

**Sounds natural**
- Friendlier, conversational replies that follow the language you speak.
- Optional natural human-like voice (OpenAI), with a choice of voices. The Windows voice is still used offline.
- You can just chat or ask questions when an AI key is set.

**Updates itself**
- VoxStride checks GitHub for new versions, verifies each download's SHA-256 checksum, and installs updates when you're not using it. You can change this under **About & diagnostics**.

> Version 0.1.0 had no updater, so install 0.2.0 manually once. After that, updates are automatic.
